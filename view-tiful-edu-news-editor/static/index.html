원문 검증

검증 전

공개 자료를 자동 검색하고 등록한 근거·인터뷰 기록과 함께 사실을 대조합니다. 의견·분석·제안은 구분해 읽습니다.

검색한 출처의 실제 본문을 읽습니다. 공개 자료가 충분하면 PDF를 직접 넣지 않아도 됩니다. 검색 실패·단일 근거·출처 충돌은 검토 화면에 표시합니다.

AI 설정 확인 중

원문을 저장하고 근거를 등록한 뒤 실행하세요.

AI 설정 안내

프로젝트의 .env.example을 .env로 복사하고 OPENAI_API_KEY에 본인의 키를 입력하세요. 서버를 다시 실행하고 화면을 새로고침하면 사용할 수 있습니다.

키는 서버에서만 사용합니다. 기사와 등록한 근거의 관련 발췌가 AI API로 전송됩니다.

날짜·숫자확인 대기
적용 대상·범위확인 대기
예외·추가 조건확인 대기
주장의 공식 근거확인 대기
판정은 실제로 읽은 근거의 발췌를 대조한 AI 검토 결과입니다. 적용 학년도·조건과 누락된 주장은 사람이 확인해야 합니다.

근거 자료 등록

아래 근거 내용에 실제 발언·취재 기록을 입력하세요. 인터뷰 내용과 기자의 의견은 구분해 사용합니다.

필요한 문장을 드래그해 선택하면 그 부분만 넣습니다. PDF의 쪽수는 파일 안의 페이지 순서입니다.

원문을 저장하면 근거를 등록할 수 있습니다.

사실·편집자 분석·기자 의견·학습 제안·인터뷰를 선택해 작성하세요. 인터뷰는 실제 취재 기록을 연결하고, 근거 없는 추가 사실은 자동 검색을 사용할 때 최종 재검증에서 확인합니다.

AI 작성 버튼을 누를 때 API를 한 번 호출합니다. 보류·제외 항목은 작성 소재에서 빼고, 원문은 그대로 보관합니다.
