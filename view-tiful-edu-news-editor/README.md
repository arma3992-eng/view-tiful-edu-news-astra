# 교육뉴스 편집실 — 의견·인터뷰·자동 검색 버전

원문을 왼쪽, 검증 준비와 근거 자료를 오른쪽에 배치한 별도 웹앱입니다.
화면은 HTML/CSS/JavaScript, 서버는 Python FastAPI, 저장은 SQLite로 구성했습니다.
Flutter 없이 PC의 웹브라우저에서 사용합니다.
원문·근거 등록 → 원문 검증 → 기사 재작성·편집 → 초안 전체 재검증 → 사람의 승인 → 기사 파일 다운로드까지 연결했습니다.
기사 제작·검토용 핵심 흐름은 구현했습니다. 기존 사이트에 실제 게시하는 연결과 운영용 로그인·배포는 별도 작업입니다.
이번 의견·인터뷰·자동 웹 검색 업데이트와 적용 방법은 docs/newsroom-guide.md를 먼저 읽어주세요.
PDF 인용·기사 수정 위치 보완은 docs/pdf-citations-guide.md에 있습니다.
이름 입력·항목별 사람 검토·승인 방법은 docs/human-review-guide.md에 있습니다.
전체 마지막 단계 사용법은 docs/final-guide.md에 있습니다.
재작성은 docs/step3-guide.md, API 키·PDF 사용법은 docs/step2-guide.md에 있습니다.

## 제작 순서

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 기사·검증 기준 정리, 별도 프로젝트와 원문·근거 저장 화면 구성 | 구현 완료. 원문과 근거를 저장하고 다시 불러온다 |
| 2 | 사실 주장 추출, 근거 확보, 원문 검증 | 구현 완료. AI 키 설정 후 판정·이유·근거 위치를 보여준다 |
| 3 | 검증 결과를 반영한 기사 재작성 | 구현 완료. 포함·수정·보류·제외와 추가 소재를 저장하고 AI 또는 직접 초안을 작성한다 |
| 4 | 기사 편집과 미리보기 | 기본 기능 구현. 제목, 2문장 요약, 세부 항목, 핵심 정보, 학생·학부모·교사 안내를 편집하고 미리본다. 세부 디자인은 검토 후 조정한다 |
| 5 | 재작성본 재검증과 사람의 최종 승인 | 구현 완료. 현재 기사·근거·검증 결과에 연결된 승인만 인정한다 |
| 6 | 기사 내보내기와 기존 사이트 연결 | 승인된 HTML·JSON 다운로드 완료. 기존 사이트 전용 게시 형식 연결은 별도 |
| 7 | 실제 운영 환경 준비 | 로그인, 백업, 배포를 준비하고 반복 작업 자동화를 필요에 따라 추가한다 |

상세 판정 기준과 앞으로 만들 데이터 구조는 docs/step1-spec.md에 있습니다.

## 이번 버전에서 할 수 있는 일

- 기사 제목·본문과 선택 사항인 원문 주소를 저장합니다.
- 근거 자료 이름, 종류, 주소, 페이지·위치, 대조할 내용을 등록합니다.
- 저장한 기사 목록에서 원문과 근거를 다시 불러옵니다.
- 원문·근거의 수정 버전을 관리하여 다른 창의 변경 내용을 덮어쓰는 요청을 거절합니다.
- 서버를 종료했다가 다시 실행해도 저장한 내용이 남습니다.
- 기사 주소에서 원문을 불러오고 확인한 뒤 저장합니다.
- 공식 자료 주소에서 내용을 읽거나 PDF를 첨부해 페이지별 내용을 확인합니다.
- AI 키 설정 후 '원문 검증 실행'으로 주장별 판정과 실제 근거 발췌를 확인합니다.
- 원문·근거가 변경되면 이전 검증 결과를 재검증 필요 상태로 표시합니다.
- 검증 항목마다 포함·근거에 맞게 수정·보류·제외를 선택합니다. 일치 이외의 항목은 보류로 시작합니다.
- 원문을 저장하면 검증 전에도 추가 소재의 유형과 내용을 작성할 수 있습니다. 현재 원문 검증을 마쳐야 편집 결정을 저장하고 초안을 작성할 수 있습니다.
- 과거 사례·트렌드·편집자 분석·기자 의견·학습 제안·인터뷰를 구분해 추가합니다.
- 실제 인터뷰 발언에 대상·역할·날짜·방법을 기록하고, 발언의 존재와 발언 속 객관적 사실을 구분해 대조하도록 요청합니다.
- 자동 웹 검색을 켜면 공개 출처를 찾고 실제 본문을 읽어 등록한 근거와 함께 비교합니다. PDF 직접 등록 없이도 실행할 수 있습니다.
- 읽은 출처 링크·검색 실패·인용 근거 수·복수 사이트와 단일 근거 여부를 표시합니다. 검색 요약은 사실 인용 근거로 사용하지 않습니다.
- 편집 결정을 저장하고 선택한 소재만으로 AI 초안을 작성합니다. 원문 전체와 보류·제외 항목은 작성 소재에 넣지 않습니다.
- 제목·요약 두 문장·세부 항목·핵심 정보·독자별 안내를 편집하며 미리보고 초안을 저장합니다.
- 재작성 기준이 바뀌면 기존 초안은 보관하고 확인 필요 상태로 표시합니다.

- 저장한 초안의 제목·요약·소제목·본문·핵심 정보·독자별 안내 전체를 최종 검증합니다.
- 미해결 항목은 문장 수정·재검증하거나 실제 근거와 사람의 판단 이유를 기록해야 승인할 수 있습니다. AI 판정은 원본으로 보존합니다.
- 사실 단정 없는 의견·분석·안내·제안은 그 판단 이유를 기록합니다. 근거와 불일치한 사실은 유형 변경으로 해제할 수 없습니다.
- 검사 범위 누락·기사 인용 오류는 항목별 사람 판단으로 우회하지 않습니다. 현재 초안 전체를 다시 검증해야 합니다.
- 검토자 이름과 사실·편집 내용·출처 및 이용 권한 확인을 입력해 현재 버전을 승인합니다.
- 승인된 기사만 출처·버전·승인 기록과 함께 HTML·JSON으로 내려받습니다.
- 기사·근거·편집 결정·검증 보고서가 바뀌면 이전 승인으로 내려받을 수 없습니다. 초안 저장은 새 버전으로 처리합니다.

최종 검증에서 일치가 나와도 자동 승인하지 않습니다. AI의 사실 추출·의미 판정에 누락이나 오류가 있을 수 있으므로 기사 전체를 사람이 확인합니다.
검토자 이름은 직접 입력한 기록이며 로그인으로 인증한 신원은 아닙니다. 출처 표기·확인 체크가 이용 허가를 자동 취득하는 것은 아닙니다.
실제 웹사이트에 자동 게시하는 기능은 별도입니다.
자료 종류의 '공식 자료'는 사용자가 선택한 분류이며 진위 확인 결과가 아닙니다.
자동 검색은 원문과 최종 기사 검증에서 각각 실행합니다. 한 번에 검색 도구를 최대 4회 호출하고 후보 본문을 최대 6개 읽습니다.
실제 인용·대상·시점·조건과 같은 원자료 전재 여부는 사람이 확인합니다. 사이트 수가 많다는 이유만으로 독립 검증 완료라고 판단하지 않습니다.
공개 PDF는 주소에서 읽을 수 있으면 자동 대조하고, 접근 제한·스캔 PDF·비공개 자료는 실제 내용을 직접 등록해야 할 수 있습니다.
웹 검색을 사용하면 AI 대조 외에 검색 API 사용료도 발생합니다. 화면의 체크를 끄면 직접 등록한 자료만 대조합니다. 승인 버튼은 AI API를 호출하지 않습니다.
원문·PDF 읽기와 저장, 편집 결정과 직접 초안 저장은 API 키 없이 사용할 수 있습니다. AI 검증·AI 초안 작성은 OpenAI API 키가 필요합니다.
편집 결정 저장·초안 생성·초안 저장에는 현재 원문·근거에 연결된 검증 보고서가 필요합니다.

## Windows / VS Code에서 실행

기존 앱은 서버를 종료하고 `.env`와 `data`를 백업한 뒤 ZIP의 코드·화면·문서를 기존 프로젝트에 복사합니다.
기존 `.env`, `data`, `.venv`는 유지합니다. ZIP에는 이 항목이 없고 이번 업데이트는 패키지 변경도 없습니다.
기존 사용자는 서버 실행 명령만 다시 입력하고 브라우저에서 Ctrl+F5를 누릅니다. 아래 환경 설치는 새 설치에 해당합니다.

Python 3.10 이상이 필요합니다. ZIP의 압축을 풀고 main.py가 있는 education-news-editor 폴더를 VS Code에서 엽니다.
기존 뉴스 사이트 폴더와 구분하여 보관하세요.

VS Code의 '터미널 → 새 터미널'에서 아래 명령을 한 줄씩 실행합니다.

    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8002

브라우저 주소창에서 http://127.0.0.1:8002 를 엽니다.
index.html을 직접 열거나 VS Code Live Server로 열면 저장 API를 사용할 수 없습니다.
종료할 때는 실행 중인 터미널에서 Ctrl+C를 누릅니다.
다음 실행부터는 마지막 서버 실행 명령만 입력하면 됩니다.

py 명령을 찾을 수 없지만 python 명령이 동작한다면 첫 줄을 python -m venv .venv로 바꿔 실행합니다.
이미 8002 포트를 사용 중이면 서버 명령의 포트를 8003으로 바꾸고 브라우저 주소도 8003으로 맞춥니다.

## macOS / Linux에서 실행

    python3 -m venv .venv
    .venv/bin/python -m pip install -r requirements.txt
    .venv/bin/python -m uvicorn main:app --reload --port 8002

## 첫 실행 확인

1. '가상 예시 넣기'를 누릅니다.
2. '원문 저장'을 누릅니다. 원문이 저장된 후 근거 입력란이 활성화됩니다.
3. 자료 이름을 '저장 테스트용 자료', 대조할 내용을 '실제 뉴스 근거가 아닌 저장 확인용 문장입니다.'로 입력합니다.
4. '근거 등록'을 누릅니다. 오른쪽에 등록된 자료가 보입니다.
5. 새로고침 후 '저장한 기사'에서 방금 저장한 기사를 선택합니다. 원문과 근거가 다시 나타나는지 확인합니다.
6. 서버를 종료하고 다시 실행해도 같은 기사를 불러올 수 있는지 확인합니다.

가상 예시는 저장 동작 확인용이며 실제 기사나 검증 결과가 아닙니다.

현재 저장소는 최신 원문·초안과 버전 번호, 검증 보고서·승인 기록을 보관합니다.
화면에는 최신 최종 검증과 최근 승인 기록을 표시합니다. 원문·초안의 모든 과거 내용을 복원하는 기능은 포함하지 않습니다.

이 버전은 개인 PC에서 실행하는 편집 기반입니다. 인터넷 운영 환경과 로그인은 7단계에서 연결합니다.
