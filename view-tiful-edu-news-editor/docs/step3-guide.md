# 3단계: 기사 재작성·편집·미리보기

의견·인터뷰·자동 검색을 포함한 최신 업데이트는 `newsroom-guide.md`를 먼저 읽어주세요. 아래는 재작성의 기본 사용법입니다.

## 업데이트

1. VS Code의 서버 터미널에서 Ctrl+C로 종료합니다.
2. 기존 data 폴더를 다른 위치에 복사하여 보관합니다. 원래 data 폴더는 프로젝트 안에 둡니다.
3. ZIP을 다른 위치에 압축 해제합니다. 그 안의 education-news-editor 내용물을 기존에 실행 중인 education-news-editor 폴더의 같은 위치에 복사합니다.
4. 기존 data, .env, .venv는 유지합니다. ZIP에는 이 폴더·설정·실제 키가 들어 있지 않습니다. 패키지 변경은 없습니다.
5. 프로젝트 터미널에서 서버를 실행합니다.

    .\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8002

6. http://127.0.0.1:8002 를 열고 Ctrl+F5로 새로고침합니다.
7. 상단 '3단계 · 기사 재작성', 메뉴의 '기사 재작성', 비교 화면 아래의 재작성 영역을 확인합니다.

전체 코드 대신 수정 파일만 옮긴다면 아래 파일을 교체·추가합니다.

- 루트: main.py, storage.py, verification.py, rewriting.py(새 파일).
- static: index.html, app.js, style.css, rewrite.js(새 파일).
- 안내·검사: README.md, docs/step3-guide.md, tests/test_workflow.py, tests/test_rewriting.py.

기존 프로젝트 안에 education-news-editor 폴더를 하나 더 만드는 대신 main.py가 있는 폴더에 내용물을 복사합니다.
첫 실행 때 editor_work 테이블이 추가됩니다. 기존 기사·근거·PDF·검증 결과를 삭제하지 않습니다.
http://127.0.0.1:8002/api/health 의 step=5, rewriting_available=true로 서버 버전을 확인합니다.

## 확인 불가 항목의 처리

재작성 단계에서는 기사에 사용할 소재를 결정합니다. 포함 결정은 사실 검증이나 게재 승인이 아닙니다.

| 결정 | 사용할 때 | 초안 처리 |
| --- | --- | --- |
| 포함 | 일치한 사실 또는 근거를 추가 확인한 사실 | 원문의 발췌를 소재로 사용. 일치 이외의 항목에는 근거와 포함 이유 필수 |
| 근거에 맞게 수정 | 원문의 숫자·조건 등을 근거에 따라 고침 | 수정 문장과 선택한 근거를 소재로 사용. 원문은 보관 |
| 보류 | 근거 부족·자료 충돌·추가 확인 중 | AI 작성 소재에서 제외 |
| 제외 | 최종 기사에 넣지 않기로 결정 | AI 작성 소재에서 제외 |

일치 항목만 기본 포함입니다. 불일치·조건 보완 필요·확인 불가·원문 인용 미확인은 기본 보류입니다.
모든 검증 항목이 일치해야 재작성을 시작할 필요는 없습니다.
원문 인용 미확인 항목은 보류·제외만 선택합니다. 필요한 내용이라면 추가 내용에 별도로 작성하고 근거를 연결합니다.
AI는 관련 근거의 발췌도 읽으므로 같은 정보가 근거 문서에 남아 있을 수 있습니다. 선택하지 않은 사실을 임의로 추가하지 않도록 요청하지만, 실제 출력이 편집 결정을 따랐는지는 미리보기와 최종 재검증에서 확인해야 합니다.

## 현재 기사로 시작

1. '저장한 기사'에서 기사를 선택합니다. 기존 검증 결과가 남아 있는지 확인합니다.
2. '기사 재작성'을 누르면 아래 재작성 영역으로 이동합니다.
3. '검증 항목별 포함·수정·보류·제외'를 펼칩니다.
4. 사용할 항목의 결정을 고릅니다. 수정하거나 확인 후 포함할 때 '수정 문장·근거·포함 이유'를 펼쳐 입력합니다.
5. '편집 결정 저장'을 누릅니다. 다음에 기사를 불러와도 결정과 추가 내용이 남습니다.
6. 'AI로 초안 작성' 또는 '직접 초안 작성'을 누릅니다.

원문·근거가 바뀌었으면 먼저 원문 검증을 다시 실행합니다. 검증 보고서가 바뀌면 그 보고서의 항목별 결정을 다시 확인하고 저장합니다.
새 검증 결과가 오면 같은 원문 인용의 결정과 작성 중인 추가 내용·초안을 화면에 보관합니다.
새 보고서의 다른 주장 번호에 이전 초안의 근거를 잘못 연결하지 않도록, 보관한 편집 초안의 소재 연결은 초기화하고 확인 필요 상태로 둡니다.
결정을 다시 확인해 저장한 뒤 새로 작성하거나 직접 내용을 확인합니다. 화면에 보관한 내용은 저장 전에는 데이터베이스에 반영되지 않습니다.
입력 중인 근거는 먼저 등록하거나 지운 뒤 재작성합니다.

## 4문항을 5문항으로 고치는 예제

첨부 이미지에는 원문이 '4문항'이며 근거 부족으로 확인 불가가 표시됐습니다.
'5문항'은 여기서 앱 동작을 설명하는 수정 후보입니다. 이번 개발에서 실제 서울시립대 문항 수를 새로 확정한 것은 아닙니다.

1. 해당 대학·학년도의 문항 수가 적힌 공식 문제지나 출제 안내를 확인합니다.
2. 5문항을 뒷받침하는 자료가 있다면 기존 근거 등록에서 자료를 등록합니다. 새 근거 등록 뒤에는 원문을 다시 검증합니다.
3. 재작성 영역에서 해당 항목을 '근거에 맞게 수정'으로 고릅니다.
4. 수정할 문장에 해당 대학·학년도와 문항 수를 명확하게 입력합니다.
5. 그 수치를 확인한 근거 자료에 체크하고 확인한 쪽·항목을 이유에 적습니다.
6. 편집 결정을 저장한 뒤 초안을 작성합니다.

5문항의 근거가 아직 없으면 이 항목을 보류하고 다른 확인된 소재로 먼저 초안을 만들 수 있습니다.
원문의 4문항을 5문항으로 직접 바꿀 필요가 없습니다. 수정 후보는 초안에만 반영하고 이후 초안 전체를 다시 검증합니다.
연결한 자료가 실제로 수정 문장을 뒷받침하는지는 사람이 확인해야 합니다. 자료를 체크한 것만으로 확인 완료를 표시하지 않습니다.

## 추가 배경 내용

'+ 추가 내용 넣기'를 누릅니다. 기사당 최대 10개입니다.

- 사실·과거 사례·트렌드: 연도·기간·대학·비교 범위를 적고 근거 자료를 하나 이상 선택합니다.
- 편집자 분석: 해석·전망임을 분명히 하고 바탕이 되는 사실 자료를 연결합니다. 미리보기에 '편집자 분석'으로 표시합니다.
- 학습 제안: 공식 의무나 대학의 정책처럼 표현하지 않습니다. '학습 제안'으로 표시합니다.

새 자료는 원문 검증 영역의 기존 근거 등록 입력란에서 하나씩 추가합니다.
근거 자료를 연결하는 것은 소재의 출처를 남기는 과정이며 사실 검증 완료를 뜻하지 않습니다.
'편집 요청'에는 독자·문장 길이·강조할 조건 같은 구성 지시를 적습니다. 이 입력란으로 사실을 추가하지 않습니다.

## AI 작성과 직접 작성

AI 작성은 저장된 편집 결정에서 포함·수정한 소재와 추가 내용만 이용합니다.
원문 전체·보류·제외 항목은 작성 소재에서 빼고, 연결한 근거의 관련 발췌는 함께 보냅니다.
AI 작성 버튼을 누를 때 한 번의 API 요청이 발생합니다. 자동 재호출은 없습니다.
오류가 나면 이미 저장된 편집 결정과 이전 초안을 보관합니다.
모든 항목을 보류·제외하고 추가 소재도 없으면 AI를 호출하지 않습니다.

직접 작성은 새 빈 편집란을 열며 AI를 호출하지 않습니다.
기존 저장 초안은 새 내용을 저장하기 전까지 보관합니다.
직접 새로 넣은 항목에 소재 연결이 없으면 초안에 근거 확인 필요 안내가 남습니다.

## 편집·미리보기·저장

왼쪽 편집란에서 아래 내용을 바꾸면 오른쪽 미리보기에 반영됩니다.

- 기사 분류·제목.
- 요약 두 문장. 실제 화면 줄 수는 창 너비에 따라 달라집니다.
- 세부 항목의 소제목·성격·본문. 항목을 추가·삭제할 수 있습니다.
- 핵심 정보 카드. 정보가 부족한 항목은 생략합니다.
- 학생·학부모·교사 안내. 내용이 없는 독자 안내는 미리보기에서 생략합니다.
- 원문 링크와 사용한 소재에 연결된 근거 목록·PDF 열기 링크.

미리보기에는 독자별 안내가 하나의 영역 안에 배치됩니다. 넓은 화면에서는 세 열, 작은 화면에서는 세로로 표시합니다.
'초안 저장'을 눌러 저장합니다. 새로고침 후 '저장한 기사'에서 불러오면 편집 결정과 초안을 복원합니다.
편집 결정 수정 중에는 초안 편집란을 잠시 잠그므로 결정을 먼저 저장합니다.
기준이 바뀐 초안은 '초안 기준 변경 · 확인 필요'로 표시합니다. 바뀐 소재로 다시 생성하거나 직접 작성해 내용을 확인합니다.
표시한 출처는 연결한 자료 목록입니다. 모든 자료의 모든 페이지를 검증했다거나 사용 허가를 받았다는 의미로 표시하지 않습니다.

## 검증과 제한

자동 검사:

    .\.venv\Scripts\python.exe -m unittest discover -s tests -v

50개 검사에서 기존 저장·PDF 기능과 재작성 소재, 4→5문항 수정 후보, 초안 복원, 잘못된 소재 ID, 요약 두 문장, 변경 충돌을 확인합니다.
AI 응답은 모의했습니다. 실제 API의 기사 품질은 본인의 키로 현재 기사와 근거를 이용해 별도로 확인합니다.
실제 FastAPI와 DOM을 연결한 추가 검사로 결정 선택→AI 초안→편집→저장→복원, 출처 링크와 상태 표시를 확인했습니다.
PC·모바일에서 시각적인 크기와 줄바꿈은 적용 후 미리보기에서 확인하세요.

이 문서는 3단계 재작성 기능 안내입니다. 최종 버전에는 초안 전체 재검증·사람의 승인·HTML/JSON 다운로드도 연결했습니다.
마지막 단계 사용법은 docs/final-guide.md를 참고하세요. 실제 웹사이트 게시는 별도이며 can_publish는 false입니다.
