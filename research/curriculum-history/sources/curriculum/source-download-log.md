# 공식 원자료 다운로드 로그

확인일: **2026-10-12 (한국시간)**

기준 파일: `curriculum-source-list.md`의 S01~S13. 분석·기사 작성 및 코호트표 수정은 수행하지 않았다.

## 확보 범위

- 공식 문서 파일 13개(PDF/HWP), 공식 웹페이지 HTML 응답 보존본 4개.
- 필수 7개 고시 모두 고시문과 시행 부칙을 포함한 파일을 확보했다. 2007-79호는 NCIC 제공 자료에 수록된 고시문, 2026-1호는 일부개정 총론에 수록된 고시문이다.
- 전 교과 별책 전집을 모두 모았다는 의미는 아니다. 2011년은 총론과 별책3 중학교 교육과정을 확보했다.
- 다운로드 원자료의 내용은 수정하지 않았다. 식별을 위해 로컬 파일명만 변경했다. PDF 쪽수는 뷰어의 1쪽부터 센 순서다.
- 웹페이지는 내려받은 HTML 응답 그대로 보존했다. 외부 자원과 화면 구성을 완전히 보존한 웹 아카이브 또는 PDF가 아니다.
- 검색·게시물 확인만 된 항목은 다운로드 완료로 계산하지 않았다. 오류 페이지도 원자료에 포함하지 않았다.
