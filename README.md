### 2. 교육 관련 데이터 및 공공자료

이 프로젝트에서는 교육 관련 통계와 학교 정보를 정리하기 위해 교육부, 시·도교육청 등에서 공개한 자료를 활용할 수 있습니다.

- 교육부 및 시·도교육청 공개자료: 각 기관의 원문 출처와 이용 조건을 따름
- AI 중점학교 관련 교육청 자료: 해당 교육청의 공개자료를 바탕으로 정리
- 기타 공공데이터 및 통계자료: 제공 기관의 이용 조건을 확인하여 사용

자료별 세부 라이선스가 명확하지 않은 경우에는 **사용 조건 확인 필요**로 처리합니다.

### 3. 기사 및 외부 웹 자료

외부 언론사의 기사와 웹페이지는 사실 확인과 취재 자료로 활용하며, 원문 전체를 복제하여 배포하지 않습니다.

기사 제목·출처·원문 URL 등을 표시하고, 기사 본문과 사진 등의 저작권은 해당 언론사 및 원 저작권자에게 있습니다.

### 4. 사진 및 이미지

외부에서 가져온 사진이나 이미지는 원 저작권자의 이용 조건을 따릅니다.

출처 또는 이용 조건이 확인되지 않은 이미지는 공개 콘텐츠에 사용하지 않거나 **사용 조건 확인 필요**로 표시합니다.

### 5. AI 생성 콘텐츠

ChatGPT 등 생성형 AI를 활용하여 기사 초안, 요약, 문장 정리 또는 이미지를 제작할 수 있습니다.

AI 생성 결과는 그대로 게시하지 않고 사람이 사실관계와 표현을 검토·수정합니다.

AI로 생성한 이미지가 사용된 경우에는 가능한 범위에서 **AI 생성 이미지**임을 표시합니다.
