# 교육뉴스 메인페이지 디자인

## 실행 방법
1. ZIP 압축을 풉니다.
2. VS Code → 파일 → 폴더 열기 → educationnews-design 폴더를 선택합니다.
3. index.html을 우클릭 → Open with Live Server를 누릅니다.
   Live Server가 없어도 index.html을 브라우저로 열면 동작합니다.
4. PC에서는 브라우저 배율 100%, 창 너비 1440px를 기준으로 확인합니다.

기존 educationnews 폴더에 덮어쓸 필요 없이 독립적으로 실행할 수 있습니다.

## 구성
- index.html: 헤더, 주요 기사, 분야별 뉴스, 주목할 만한 기사, 관심 분야, 독자별 가이드, 푸터
- style.css: 시안 기반 색상·글자·간격과 모바일 대응
- script.js: 캐러셀 자동·수동 전환, 독자별 가이드 선택, 예시 기사 검색, 미리보기 팝업
- lead-news.js: 당일 대표뉴스 3개의 이미지·영상·제목·요약 데이터
- article.html, article.js: 대표뉴스의 기사 화면과 하단 핵심 요약
- assets/: 첨부 시안에서 추출한 기사 사진

## 확인
- 메인 기사 오른쪽 ‹ › 버튼 또는 하단 01~03 기사 탭 클릭
- 하단 AI교육 / 교육정책 / 에듀테크 선택 후 안내 내용 변경 확인
- 검색창에 AI 입력 후 Enter
- 기사 클릭 → 예시 안내 팝업 → Esc로 닫기
- 브라우저 개발자 도구에서 너비 390px로 모바일 화면 확인

## 현재 범위와 시안 차이
- 첨부 이미지를 기준으로 재구성했으며 원본 Figma의 정확한 글꼴·수치 정보는 제공되지 않았습니다.
- 글꼴은 PC에 설치된 Pretendard → Noto Sans KR → 맑은 고딕 순서로 적용됩니다. 운영체제에 따라 글자 폭과 줄바꿈이 조금 달라질 수 있습니다.
- 사진은 시안에서 추출한 이미지라 원본 고해상도 사진보다 선명도가 낮습니다.
- 파란 Figma 선택 테두리와 크기 표시는 실제 디자인 요소가 아니므로 제외했습니다.
- 2·3번 캐러셀은 같은 시안에서 가져온 사진과 예시 요약을 사용합니다.
- 하단 첫 번째 가이드는 시안 문구를 옮겼으며 두 번째·세 번째 가이드는 동작 확인용 예시입니다.
- 대표뉴스는 기존 예시 기사로 구성되어 있습니다. 대표뉴스 요약 링크는 article.html의 핵심 요약으로 연결됩니다. 실제 기사 본문·영상·서버 검색은 준비 전이며, 다른 기사 클릭 시 예시 안내 팝업이 열립니다.
- 캐러셀은 기본 8초 간격으로 1 → 2 → 3 → 1 순서로 자동 전환합니다. 마우스를 올리거나 캐러셀 안에 키보드 초점이 있으면 잠시 멈춥니다. 일시정지 버튼으로 멈추고 재생할 수 있습니다. 동작 줄이기를 설정한 기기에서는 자동 넘김이 기본 정지됩니다.

## 수정 위치
- 전체 폭·기본 색상: style.css 맨 위 :root
- 메인 기사와 핵심 요약 데이터: lead-news.js의 LEAD_NEWS
- 독자별 가이드: script.js의 guides
- 메뉴·분야별 목록·카드 문구: index.html

## 헤더 메뉴와 홈 이동
- 헤더 로고: 뷰티풀 에듀 (View-tiful Edu). 클릭하면 index.html로 이동합니다.
- 입시•수능: category.html?type=admissions
- 영재•특목: category.html?type=gifted
- AI•디지털교육: category.html?type=digital
- 학교•교육정책: category.html?type=school-policy
- ABOUT: about.html
- 분야별 목록은 기존 메인페이지의 예시 기사로 구성되어 있습니다. 영재•특목은 아직 등록된 기사가 없습니다.
- 새 페이지의 동작은 pages.js에서 관리합니다. 메인페이지의 캐러셀 동작은 script.js에서 관리합니다. 분야별 기사 목록 데이터는 news-data.js에서 관리합니다.
- 모바일에서는 메뉴 줄을 좌우로 움직여 모든 메뉴를 확인할 수 있습니다.
- 수정본 적용: index.html, style.css, README.md를 교체하고 category.html, about.html, pages.js를 같은 폴더에 추가합니다.
- 로고 클릭, 다섯 메뉴 클릭, 목록의 검색과 검색 초기화를 차례로 확인하세요.

## 대표뉴스 캐러셀과 핵심 요약
- 8초 자동 전환: 이미지 또는 영상, 분류, 제목, 요약, 번호, 파란 표시줄이 동시에 바뀝니다.
- 이전·다음 화살표, 하단 기사 탭, 키보드 좌우 화살표로도 전환할 수 있습니다.
- 기획 기사 • 2분 읽기 링크는 선택한 기사의 article.html?id=lead-1#summary 등으로 이동합니다.
- 현재는 영상 파일이 없어 사진으로 표시합니다. 영상이 준비되면 assets 폴더에 넣고 lead-news.js의 해당 기사의 video 값을 'assets/news-1-preview.mp4'처럼 지정하세요.
- 전체 영상이 따로 있으면 fullVideo에 경로를 넣으세요. 비워두면 같은 영상을 확대 재생합니다.
- 영상은 메인에서 음소거·반복 재생되며 클릭하면 전체 영상 플레이어가 열립니다. 영상 재생 오류 시 사진으로 표시합니다.
- 새 기사 화면의 핵심 요약은 summary 배열을 수정하면 됩니다. 제목·이미지·요약은 캐러셀과 기사 페이지가 같은 데이터를 사용합니다.
- 이번 수정본 적용: index.html, style.css, script.js, pages.js를 교체하고 lead-news.js, article.html, article.js를 같은 폴더에 추가합니다.
- 확인 순서: Ctrl + F5 → 마우스를 캐러셀 밖에 두고 8초 대기 → 번호·기사·표시줄 변경 확인 → 하단 기사 클릭 → 기획 기사 • 2분 읽기 클릭 → 해당 핵심 요약 확인.

## 오른쪽 관심 분야 뉴스 목록
- 제목: 관심 분야로 읽는 교육뉴스
- 분야: 입시•수능 / 영재•특목 / AI•디지털교육 / 학교•교육정책
- 분야명을 누르면 해당 분야의 기사 모음 목록으로 이동합니다.
- 기사 제목을 누르면 article.html?id=... 형태의 개별 뉴스 페이지로 이동합니다.
- 분야 목록의 사진, 제목, 기사 보기 링크도 같은 뉴스 페이지를 엽니다.
- 개별 뉴스 페이지의 아래쪽 링크로 해당 분야의 기사 목록으로 돌아올 수 있습니다.
- 기존 예시 기사 제목을 유지했습니다. 본문이 준비되지 않은 기사는 준비 안내가 나옵니다. 영재•특목은 아직 등록된 기사가 없습니다.
- news-data.js는 분야 목록과 기사 페이지가 공유하는 기사 데이터입니다. 기사 고유 ID는 유지해야 기존 링크가 계속 동작합니다.
- 수정본 적용: 압축 안의 파일을 같은 이름의 기존 폴더에 반영하세요. 새 파일 news-data.js도 함께 넣어야 합니다.
- 확인: Ctrl + F5 → 오른쪽 분야명 클릭 → 목록 확인 → 기사 제목 클릭 → 뉴스 페이지 확인 → 아래 목록으로 돌아가기 클릭.
